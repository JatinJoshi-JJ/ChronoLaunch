Help & Knowledge Base

Frequently Asked Questions

Everything you need to know about ChronoLaunch architecture, precision wall-clock engine, Gemini AI intelligence, and privacy.

01 Will my countdowns remain saved if I refresh or close the tab?

Yes, completely. All timers, event metadata, custom milestone checklists, favorite stars, and UI preferences are securely persisted in your browser's local sandbox via standard localStorage.

Your data stays preserved across browser restarts, tab closures, and computer reboots without requiring any login, registration, or third-party cookies.

02 How does ChronoLaunch guarantee drift-free timer accuracy when tabs sleep?

Traditional countdown widgets decrement a local JavaScript counter once every 1,000 milliseconds. When tabs go into background throttle mode, operating systems delay these intervals, accumulating significant clock drift over hours.

ChronoLaunch bypasses this issue entirely by computing the true mathematical delta between the system epoch time (Date.now()) and your target timestamp on each animation tick. The calculation is 100% immune to tab sleeping or background suspension.

03 How does the Gemini AI Assistant work, and is an API key mandatory?

An API key is completely optional! ChronoLaunch operates in a hybrid dual-mode setup:

  • Zero-Config Mode: A built-in offline heuristic natural language parser parses conversational phrases (e.g. "Project launch in 14 days at 4 PM") instantly without network requests.
  • Gemini Cloud Mode: Adding your free Google AI Studio API key activates deep multimodal semantic analysis and comprehensive preparation briefings. Your key is stored solely on your local device.
04 How do browser notifications and milestone alerts work?

ChronoLaunch leverages the standard W3C Web Notifications API. When enabled in the Reminders Center, background checks dispatch native OS alerts at key threshold milestones:

05 Can I schedule events across international timezones and daylight saving?

Yes. You can pick your target timezone directly in the event creation form (UTC, New York EST/EDT, London GMT/BST, Paris CET, India IST, Tokyo JST, Sydney AEST).

The engine automatically maps the selected zone to absolute UTC time while intelligently accounting for daylight saving shifts, ensuring all participants sync to the exact same second regardless of geographic location.

06 What is Focus Mode and when should I use it?

Focus Mode transforms the dashboard into an ultra-clean, cinema-grade fullscreen countdown view. It strips away navigation bars, dashboard side panels, and form controls, displaying only high-impact oversized typography and dynamic pulse lighting.

It is ideal for live stream overlays (OBS/Twitch), boardroom presentation screens, stage keynotes, and focused pomodoro sessions. Press the Focus Mode button or hit the ESC key anytime to exit.

07 How are countdown milestones and roadmaps structured?

Whenever an event is activated, ChronoLaunch calculates dynamic readiness checkpoints proportional to your remaining timeline:

  • Kickoff & Research: Foundational preparation and milestone scoping.
  • Halfway Progress Check: Core deliverables and timeline validation.
  • Final Rehearsal (T-24h): Final dry-run and resource verification.
  • Zero Hour Execution: Launch moment checklist.

You can interactively check off stages and the system automatically calculates your completion percentage.

08 Does ChronoLaunch work without an active internet connection?

Yes, 100%. ChronoLaunch is designed from the ground up on modern offline web standards. All timer loops, local storage reads/writes, voice recognition APIs, and offline NLP parsing run directly in your local browser sandbox.

You can run ChronoLaunch in offline field environments, airplane mode, or unstable mobile networks without missing a beat.

09 How many events can I store and manage simultaneously?

There is no arbitrary limit. You can maintain dozens of concurrent countdowns across categories like Product Launches, Examinations, Birthdays, Vacation Trips, and Deadlines.

Use the dashboard filter tabs (All, Active, Completed, Starred) to quickly organize your milestones, and click any card's "Set as Active" button to promote it to the main showcase.

10 Does ChronoLaunch track my events or sell telemetry data?

Never. ChronoLaunch includes zero third-party trackers, zero advertising scripts, and zero analytical cookies. Your countdown details never touch an external database.

When utilizing your optional Gemini API key, network requests travel directly and securely from your browser to Google Cloud via encrypted TLS, without passing through any intermediate proxy server.
